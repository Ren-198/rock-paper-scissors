# Rock Paper Scissors Web Game

A simple interactive Rock Paper Scissors game built using JavaScript, where users can play against the computer and track scores in real time.

---

## What This Project Does

This project allows a user to play Rock Paper Scissors against the computer through a web interface. The game keeps track of both the player’s score and the computer’s score and displays the result after each round.

---

## Why This Project Is Useful

This project helped me practice:
- JavaScript logic and conditionals
- DOM manipulation
- Updating UI dynamically
- Basic game logic implementation

It’s a good beginner project for understanding how JavaScript interacts with HTML.

---

## How to Play

1. Open the game in your browser  
2. Choose Rock, Paper, or Scissors  
3. The computer will randomly select its move  
4. The result will be displayed (Win, Lose, or Tie)  
5. Scores update after each round  

---

## How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Double-click `rps.html` to launch the game in your browser  

No installation required.
